# Trombones S.A.

Petit idle de gestion façon *Universal Paperclips* : vous fabriquez des trombones, vous vendez, vous automatisez, vous cherchez à tout convertir.

Objectif : **1 000 000 de trombones**.

## Lancer

```bash
npm install
npm run dev
```

Build : `npm run build` puis `npm run preview`.

La partie est sauvegardée dans `localStorage` (`trombone-sa-v1`).
